# プロダクト概要

**Large Folder Finder** は、Windows 上のフォルダーを高速に走査し、指定サイズ以上のフォルダーだけを Tree 形式で可視化するデスクトップアプリケーションです。

ディスク容量の圧迫原因を「どこが重いのか」という粒度で素早く特定することを目的としており、特に **NAS などネットワークドライブの探索** で真価を発揮します。

- 作者: Ryoma Henzan / Cat & Chocolate Laboratory
- ライセンス: MIT（表記が難しい場合の代替条件を README に明記）
- 配布形態: GitHub Releases での zip 配布（単一 exe）。既定は .NET 10 のランタイムを同梱した自己完結版（約140MB）で、.NET 10 Desktop Runtime を前提とする軽量なフレームワーク依存版（約1MB）もあわせて配る

## コア機能

1. **高速スキャン** — Win32 API を直接呼び出し、並列処理と組み合わせて「C++ 並の速度」を目標に据える。実測値を README で公開している（例: 約 400GB / 117万ファイルを 5〜13 秒）。
2. **スキャン結果の永続化とタブ表示** — 走査結果はローカルに保存され、複数タブで同時に閲覧できる。
3. **再スキャン不要の表示変更** — フィルタ・ソート・単位・折りたたみ・ファイル表示有無などは保存済みデータに対して適用する。走査は 1 回で済ませる。
4. **出力とクリップボード連携** — 画面の見た目（折りたたみ状態を含む）をそのままテキスト出力できる。容量整理の資料としてそのまま使える形にする。
5. **多言語対応** — OS の言語設定を自動判定し 13 言語に対応。

## 想定ユースケース

- NAS / ファイルサーバーの容量逼迫時に、原因フォルダーを短時間で突き止める
- 定期的な容量棚卸しで、結果をテキスト化して報告資料に貼り付ける
- ローカルドライブの肥大化調査

## 提供価値

**「待たされない」ことが最大の価値**です。以下の設計判断はすべてこの一点に紐づいています。

- 大規模・低速なネットワーク越しでも実用的な待ち時間に収める（速度は機能である）
- 一度走査したら、見方を変えるために再走査させない
- ランタイム導入不要（既定の自己完結版はランタイムを同梱）・インストール不要で、zip を解凍して exe を起動するだけで使える

## 設計上の優先順位

判断に迷った場合の基準:

1. **スキャン速度** — ここを犠牲にする変更は原則採用しない。**目標は WizTree と同等以上**（2026-09-22 利用者の決定。場面ごとの目標は roadmap.md の「速度の目標」）
2. **再スキャンを強いないこと** — 表示系の変更は保存済みデータ側で解決する
3. **導入の手軽さ** — 依存の追加、ランタイム要件の引き上げには慎重に。自己完結版の「ランタイム導入不要」は崩さない（大きさと引き換えに守っている。軽さはフレームワーク依存版で補う）
4. 機能の豊富さ — 上記 3 つと競合する場合は劣後する
