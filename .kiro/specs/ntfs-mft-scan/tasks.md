# Implementation Plan

> 試験・計測の前に、利用者のアプリデータ（`%LOCALAPPDATA%\Cat & Chocolate Laboratory\LargeFolderFinder`）を退避し、終わったら復元する。ビルドは `dotnet build LargeFolderFinder.sln -c Release -warnaserror`、テストは `dotnet test --solution LargeFolderFinder.sln -c Release --no-build`。
>
> **管理者権限の制約（最重要）**: 目録を読む走査は管理者でしか動かず、**開発の作業と自動の試験は管理者ではない状態で行う**。そこで設計を「目録の読み取り（管理者が必要）」と「木の組み立て（管理者は不要）」に分け、後者は作った並びで自動に確かめる。管理者が要る確認は利用者が行う（タスク8）。**どのタスクも、管理者でない環境で `dotnet test` が緑のまま完了できること**を条件にする。
>
> **利用者に委ねる検証**: 目録の読み取りの実機確認（速さ・取れる値・アクセス権の無い場所）、WizTree との比較（要件1.2、7.2〜7.4）、画面での見え方（昇格の確認、走査の方式の表示、起動時の昇格）、管理者権限を持たない別のアカウントでの起動。手順はタスク 7.1 で整え、作業はタスク8 に置く。
